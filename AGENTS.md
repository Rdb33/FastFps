# Consignes du projet FastFps

## Versions et publications

Les numéros suivent les règles définies par le propriétaire, au format `A.B.C` :

- **Nouvelle version** : incrémenter `B` et remettre `C` à zéro. Exemple : `1.2.4` → `1.3.0`.
- Si cette incrémentation porte `B` à 10, incrémenter `A` et remettre `B` et `C` à zéro. Exemple : `1.9.4` → `2.0.0`.
- **Snapshot** : incrémenter uniquement `C`, sans plafond ni report sur `B`. Exemples : `1.2.4` → `1.2.5`, `1.2.9` → `1.2.10`, `1.2.10` → `1.2.11`.
- Si le propriétaire ne précise pas si les changements constituent un snapshot ou une nouvelle version, lui demander de choisir avant toute publication. Les travaux d'implémentation indépendants de ce choix peuvent avancer.
- Toujours demander l'accord du propriétaire avant un push. Un accord explicite pour la publication concernée suffit ; ne pas le redemander pour la même publication.
