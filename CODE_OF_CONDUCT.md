# Code de conduite de FastFps

## Un espace accueillant

Toute personne est bienvenue pour jouer, discuter, signaler un problème ou contribuer, quels que soient son origine, sa nationalité, son âge, son genre, son orientation sexuelle, sa religion, son handicap ou son niveau d'expérience.

Nous demandons à chaque membre de faire preuve de respect, de patience et de bonne foi. Les désaccords techniques se discutent en expliquant les faits et les choix possibles. Les critiques portent sur le travail et les comportements, sans attaque personnelle.

## Comportements attendus

- Accueillir les nouveaux membres et expliquer les points difficiles sans les rabaisser.
- Respecter les différences de point de vue, les limites personnelles et les décisions de modération.
- Donner et recevoir des critiques constructives ; reconnaître et corriger ses erreurs.
- Respecter la vie privée et demander l'accord d'une personne avant de partager ses informations.
- Créditer les contributions et les contenus utilisés.

## Comportements interdits

Le harcèlement, les menaces, les propos discriminatoires, les insultes, les attaques personnelles, les avances sexuelles non sollicitées, la publication d'informations privées, l'usurpation d'identité et le spam ne sont pas acceptés. Cela comprend les tentatives de contourner une mesure de modération.

## Portée

Ce code s'applique aux issues, pull requests, commentaires et autres espaces officiels du projet, ainsi qu'aux échanges où une personne représente officiellement FastFps. Il concerne aussi les sessions de jeu organisées par le projet.

## Signaler un incident sans publier de données personnelles

Le responsable de la modération du projet est [Rdb33](https://github.com/Rdb33).

Pour demander un échange privé avec le mainteneur, ouvre une [issue](https://github.com/Rdb33/FastFps/issues/new) intitulée **« Demande de contact privé »**, sans décrire l'incident, identifier les personnes concernées ou publier de données personnelles. Le mainteneur pourra convenir d'un canal privé avant de recueillir les détails. Aucune adresse personnelle n'est publiée dans ce dépôt.

Pour signaler confidentiellement un contenu abusif directement à GitHub, utilise l'option **Report content** du contenu concerné, selon le [guide de signalement de GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Ces signalements sont traités par GitHub ; ils sont distincts de la modération interne du projet.

Les failles de sécurité suivent la procédure séparée de [SECURITY.md](SECURITY.md).

## Traitement et modération

Le mainteneur examine les faits et prend des mesures adaptées à leur gravité : demande de correction, avertissement, limitation temporaire des interactions ou exclusion. Une situation grave peut justifier une exclusion immédiate. Les messages contraires à ce code peuvent être retirés.

Les informations confiées en privé sont limitées aux personnes nécessaires au traitement du signalement. Les représailles envers une personne ayant effectué un signalement de bonne foi sont interdites. Une contestation doit pouvoir être adressée au mainteneur par le canal privé convenu, sans nouvelle attaque contre les personnes concernées.
